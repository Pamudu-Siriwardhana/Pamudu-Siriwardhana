## 🚀 Featured Projects

### 🔧 [FixIT](https://github.com/Pamudu-Siriwardhana/FixIT): a trusted marketplace for independent technicians
*Built for the **Hack For Humanity** hackathon.*

Independent electricians, plumbers and carpenters mostly find work by word of mouth, keep no earnings records, and have no protection from price disputes. Customers struggle to find honest help nearby. FixIT makes the whole job transparent, from finding a technician to getting paid.

| | |
|---|---|
| 🛡️ **Trust** | Admin-verified customers and technicians (NIC + documents), plus public ratings |
| 💰 **Fair pricing** | Admin-defined price range per profession; both sides negotiate inside it |
| 🤖 **AI matching** | Describe a problem in **English, Sinhala or Tamil** and an AI model suggests the right profession |
| 🗺️ **Maps & routes** | Nearest-first technician search, plus turn-by-turn routes to each job |
| 📊 **Business toolkit** | Bookings, job tracking, payment records and an earnings dashboard |

**Built with:** Java 17 · Spring Boot 3 · Spring Security · Spring Data JPA · Thymeleaf · H2 · Leaflet / OpenStreetMap · Groq · Geoapify · JUnit 5 · Mockito
